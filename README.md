
# 🧹 Automated Data Cleaner

A Python-based web application that helps users analyze and clean CSV datasets with just a few clicks.

## 🚀 Features

- Upload CSV files
- Analyze rows and columns
- Detect missing values
- Detect duplicate rows
- Standardize column names
- Fill missing numeric values using the median
- Fill missing text values with "Unknown"
- Remove duplicate records
- Download cleaned data as a CSV file

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit

## 💻 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/automated-data-cleaner.git
   ```

2. Open the project folder:

   ```bash
   cd automated-data-cleaner
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   streamlit run app.py
   ```
